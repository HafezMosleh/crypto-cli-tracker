## 🌟 Overview
Keep your eyes on the market without leaving your IDE. This lightweight CLI tool connects to the Binance API to fetch and display real-time cryptocurrency prices. Minimal, fast, and completely terminal-based.

## ✨ Key Features
- ⚡ **Real-time Data**: Fetches live prices directly from Binance API.
- 🖥️ **Terminal Native**: Clean, colorful output tailored for developers.
- 🪶 **Zero Dependencies**: Uses Python's built-in libraries (no bulky modules).

## 🚀 Getting Started

### Prerequisites
Make sure you have `Python` installed on your local machine.

### Installation
```bash
git clone https://github.com/HafezMosleh/crypto-cli-tracker.git
cd crypto-cli-tracker
python3 -m pip install -r requirements.txt # if any
```

### Usage
```bash
python3 main.py
```
